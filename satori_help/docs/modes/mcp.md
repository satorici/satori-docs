# MCP server

Documentation for the Satori MCP server is split into:

- [Setup](/modes/mcp/setup) — install credentials and configure Cursor, Claude Code, or Codex
- [Setup (Agents)](/modes/mcp/setup-agents) — steps an agent follows to install the server and the verification rule by itself
- [Tools](/modes/mcp/tools) — tool catalog, playbook runners, and remote sandboxes
- [Agent rules](/modes/mcp/agent-rules) — recommended project rules so agents do not skip the Satori tests
- [Subagents](/modes/mcp/subagents) — optional dedicated verifier subagents
- [Reference](/modes/mcp/reference) — MCP resources, built-in prompt, and errors
